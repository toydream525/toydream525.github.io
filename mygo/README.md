## 运行源码

本目录为官网构建产物。Release 的 `mygo-demo.zip` 包含 React / TypeScript / Vite 源码、素材、测试、构建文件和启动说明。解压后在 `mygo-demo` 目录运行：

```sh
npm install
npm run dev
```

`npm test` 运行测试；`npm run build` 构建；`npm run preview` 预览构建版本。

角色与原作素材归各自权利人所有。素材与语音来源、模型许可及同人台词说明见源码包中的 `ASSETS.md` 和相关许可文件。
