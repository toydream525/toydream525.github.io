GET STARTED

三步，开始使用

本地试聊与 DSH Agent 所需组件不同，按自己的目标准备即可。

  1. 01↓

    准备必要文件

    准备伴航、完整的 llama.cpp Windows 引擎包，以及适合电脑的 GGUF 模型。只有使用 DSH Agent 时，才另需 Node.js 和完整的 DeepSeek Harness 本地安装。

  2. 02▤

    入库与导入配置

    在应用中检测引擎并导入模型。可选择内置 Qwen 参考配方；按提示绑定对应模型与固定模板。资源缺失会列出待绑定项。

  3. 03▷

    启动并实际验证

    等待模型 API 就绪，在试聊里检查回答。需要 Agent 时，再连接已认证的 DSH、设置本地提供方，并用新会话验证工具工作流。

从 llama.cpp 官方发布页 ↗选适合系统和显卡的 Windows 构建，完整解压 EXE 与 DLL。原目标 4080 的已测版本为 b11149 Windows x64 CUDA 12 主包及同页 CUDA 12.4 DLLs ↗；这不是所有电脑的通用选择。

COMMON QUESTIONS

常见问题

DSH 伴航支持哪些模型？

支持可由所选 llama.cpp 引擎加载、元数据完整的 GGUF 模型。内置 Qwen 配方是可选参考；其他模型应按自己的架构、量化与电脑资源设置参数，并实际验证聊天和工具能力。

我必须有 RTX 4080 才能用吗？

不用。应用可选择 CPU 或适配的 GPU 引擎；27B 与 32K 档位需要较多资源，原机结果只适用于 i7-13700K、RTX 4080 16 GB、64 GB RAM。配置较低时可从更小的 GGUF 和较短上下文开始。

需要 DeepSeek 的 API Key 吗？

本地模型试聊不需要云端 DeepSeek API Key。要使用 DSH Agent，仍需安装并认证 DSH，再把本地模型 API 设为提供方。云端模型是另一项选择，可能产生费用。

导入配方会自动下载或启动吗？

不会。导入会预览资源并保存已能绑定的预设；缺失模型或模板会列明待绑定项，也不会覆盖同名自定义参数。之后由你在工作台选择并启动。

启动后怎样确认真的可用？

等待应用报告 API 就绪，再用试聊确认中文回答。要使用 DSH，另做提供方连接测试，并在新会话里验证真实工具任务。只看到模型文件或进程存在，还不能算完成。

高级 64K、视觉和 MTP 能直接开吗？

这些是后续条件式实验。先在自己的电脑完成 32K 或更小档位的稳定验证，再按引擎能力、显存和独立测试结果逐步尝试；应用不会把未验证档位作为默认设置。
