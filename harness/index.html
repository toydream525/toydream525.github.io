COMMON QUESTIONS

常见问题

三种前端有什么区别？

Harness Web 是浏览器网页端，Harness Desktop 是 DeepSeek 官方桌面应用，Pi WebUI 是第三方开源网页界面。伴航提供启动入口与本地模型管理。

使用前需要准备什么？

请自行准备本地模型与运行时。Harness Desktop 和 Pi WebUI 也需要你自行安装；伴航不会捆绑或自动安装这些外部组件。

可以只启动模型或前端吗？

可以。模型与前端可分别操作；一键启动会先启动模型，再启动所选前端。

升级会保留已有设置吗？

使用 v0.2.0 安装版覆盖升级后，已有应用配置与模型路径会保留。
