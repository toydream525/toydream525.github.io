# YuriAqua 官网 V2 测试页

独立预览地址：`https://yuriaqua.com/preview/home-v2/`。

## 边界

所有新增页面、样式、脚本与压缩图均在本目录。没有修改主站 index.html、CNAME、robots.txt、sitemap.xml、现有产品页或共享资源。页面带有 noindex,nofollow,noarchive，不加入站点地图。测试页是公开链接，不是密码保护页面。

## 扩充应用

1. 编辑本目录 catalog.json，为新应用添加唯一 id、名称、描述、分类、平台、状态、图片、详情和源码地址。
2. 图片放到 assets/；平台和状态只填写已核实的信息。
3. 在仓库运行 `python3 preview/home-v2/build.py`，只重建本页卡片和分类按钮。
4. 本地 `python3 -m http.server 8769 --bind 127.0.0.1`，访问 `/preview/home-v2/`。

应用以静态 HTML 输出，没有 JS 也能查看并使用链接；筛选、搜索、每次 6 个的渐进展示由轻量原生 JS 增强。不使用前端框架、外部字体、公共 CDN、分析脚本、Service Worker。

## 设计及内容

中文浅色软件作品官网；以实际产品展示为中心，少量淡粉紫花形点缀。SiteCam 手机/平板真机截图与现站产品示意素材复制后转为 WebP，本目录资源不修改原始素材。

当前 /blog 尚未上线，因此博客区明确为筹备中，不虚构文章和数据，也不创建或改写 /blog。SiteCam 鸿蒙版注明商店审核中；迷星牌局注明非官方同人游戏。

## 转正

此版本不会自动转正。确认视觉与内容后，再另行安排主页替换与测试目录清理。回滚当前预览只需移除本目录或撤销仅新增本目录的提交，其他页面不需要还原。
