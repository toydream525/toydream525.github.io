HarmonyOS

🌸 鸿蒙版 0.3.5

断网时仍可拍照和记录可用卫星坐标；没有可用定位时仍可拍照并使用工程中手填地点，资料也可照常导出。地址不可用时可手动填写。

鸿蒙版不申请应用联网权限；具体地址由系统服务提供，系统服务可能使用网络。完全断网时可能无法自动获取具体地址，可手动填写。

定位结果受系统位置服务、权限和卫星信号影响。成功获取时显示可用高度；未获取到高度时不显示为 0 米。高度供现场记录参考，不作为测绘数据或海平面高程数据。

使用前的小提醒

照片在哪里？会不会误删？

照片保存在哪里？

默认保存在应用内。卸载或换机前，请先导出需要保留的资料。

系统相册和应用里的照片，会一起删除吗？

安卓版开启“同时在系统相册显示”后，两边共用同一份文件。系统相册删除后，应用会同步隐藏；从回收站恢复后会重新显示。鸿蒙版的“另存到系统相册”会多存一份，两份互不影响。

一定要注册账号、打开定位吗？

不需要注册账号。没有定位结果时仍可拍照；鸿蒙版支持地址与坐标记录，地址不可用时可手动填写。拒绝录音仍可录制无声视频。

遇到问题，去哪里反馈？

可以在 GitHub 提交问题。请说明手机型号、版本和操作步骤；发截图前记得遮住个人信息。
